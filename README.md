# 🎃 Nightfall

## 📌 Sobre o projeto

O Nightfall é um projeto acadêmico desenvolvido com temática de Halloween, com o objetivo de praticar conceitos de desenvolvimento web e criação de interfaces.

O site apresenta elementos visuais temáticos e componentes interativos para proporcionar uma experiência de navegação dinâmica.

## 🛠️ Tecnologias utilizadas

- HTML5
- Bootstrap
- CSS3

## ✨ Funcionalidades

- Carrossel de imagens.
- Galeria temática.
- Modais interativos.
- Curiosidades sobre Halloween.
- Layout com temática visual de Halloween.

## 🎯 Objetivo acadêmico

Aplicar conhecimentos de desenvolvimento web, estruturação de páginas HTML e utilização de componentes do Bootstrap.
